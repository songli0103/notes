# 🧩 平台组件

私有化部署平台实际使用的组件工具箱——每个组件一个目录，存组件档案（定位/架构/运维要点）+ 实战主题。

## 组件地图（按平台链路排列）

| 组件 | 目录 | 一句话定位 | 优先级 |
|---|---|---|---|
| [[FluxCD]] | FluxCD/ | 客户集群组件交付（GitOps） | ⭐⭐⭐ |
| [[KPS]] | KPS/ | 集群级监控全家桶（Prometheus Operator） | ⭐⭐⭐ |
| [[Keep]] | Keep/ | 告警聚合与工作流自动化 | ⭐⭐⭐ |
| [[SigNoz]] | SigNoz/ | 应用级观测（APM/trace/日志，OTel 原生） | ⭐⭐ |
| [[cert-manager]] | cert-manager/ | 证书自动签发与轮换 | ⭐⭐ |
| [[Centrifugo]] | Centrifugo/ | 实时消息推送（前端事件通道） | ⭐⭐ |
| [[SpiceDB]] | SpiceDB/ | 关系型鉴权（Zanzibar，多租户权限） | ⭐⭐ |

## 观测三件套的分工（防混淆）

```
KPS      → 集群级：节点/Pod/控制面指标 + 经典告警规则
SigNoz   → 应用级：trace / APM / 日志（OpenTelemetry）
Keep     → 告警层：多源汇聚、去重聚合、工作流自动化
```
